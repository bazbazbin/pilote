# Pilote
Pilote est un outil de gestion de projet qui permet de créer des projets et d'y organiser ses tâches.
Chaque tâche a un titre, une échéance et une priorité, et se range dans un tableau à trois colonnes : À faire, En cours, Terminé.
Je le construis pas à pas pour apprendre le développement web, du HTML jusqu'à la mise en ligne.
